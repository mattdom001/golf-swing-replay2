


GOLF SWING REPLAY
PROJECT CONTEXT
==============================

PROJECT GOAL
------------

Build a simple automatic golf swing replay system for a garage hitting mat.

The system should:

1. Continuously monitor a golfer with a camera.
2. Maintain a rolling video buffer.
3. Detect the sound of club/ball impact.
4. Preserve video from approximately 3 seconds before impact.
5. Continue recording approximately 1.5-2 seconds after impact.
6. Automatically replay the swing in slow motion.
7. Return automatically to a READY state for the next shot.
8. Require no keyboard/mouse interaction during a practice session.

CURRENT WORKING FEATURES
------------------------

VERSION 1 HAS BEEN SUCCESSFULLY TESTED.

Working:

- Live video
- Rolling video buffer

- Manual SPACE BAR trigger
- Approximately 1.5 seconds post-impact capture

- Automatic return to READY state


CURRENT DEVELOPMENT
-------------------

Version 2 added:

- NexiGo microphone input
- Real-time microphone level
- Automatic impact detection
- Configurable impact threshold
- Manual SPACE trigger retained as backup
- Approximate impact frame marker during replay

Current impact threshold starting point:

IMPACT_THRESHOLD = 0.25

This will need to be calibrated in the actual garage.

Version 3 implements:

- Explicit application states and microphone-trigger gating
- Modular camera, audio, replay, UI, storage, and application code
- Full-screen menus and Quick Practice
- User, club, session, and shot tracking
- Python dataclasses with local JSON persistence
- Adjustable replay controls and impact-centered playback
- Save/discard prompt; videos are written only when selected
- Saved swing history and session summaries

Deferred:

- Microphone calibration
- Xbox controller support
- Interactive settings controls
- High-speed and dual-camera capture
- Automatic swing analysis

IMPORTANT DESIGN PRINCIPLE
--------------------------

Keep the application LOCAL.

The finished golf replay system should not require:

- Internet
- Cloud services
- ChatGPT
- External servers

ChatGPT can assist with development, but the finished application
should run independently.
